# Baozi

[![build](https://github.com/l0rraine/baozi/actions/workflows/build.yml/badge.svg)](https://github.com/l0rraine/baozi/actions/workflows/build.yml)
[![release](https://img.shields.io/github/v/release/l0rraine/baozi?label=release)](https://github.com/l0rraine/baozi/releases)
[![license](https://img.shields.io/github/license/l0rraine/baozi)](LICENSE)
[![Go](https://img.shields.io/badge/Go-1.27.3-00ADD8?logo=go)](go.mod)
[![Windows](https://img.shields.io/badge/platform-Windows%2010%2F11-0078D4?logo=windows)](https://github.com/l0rraine/baozi)

Windows 上的快速启动器：**双击 Ctrl 唤出**，一个浮窗里搜文件、搜应用、跑自定义命令，顺带把文件传给手机或另一台电脑。

界面是原生自绘的（Direct3D，不背 WebView2）：磨砂玻璃浮窗、大圆角、柔和投影，跟随系统深浅色。

```
双击 Ctrl  →  浮窗  →  输入  →  ↑↓ 选择  →  Enter 打开
```

## 下载

去 [Releases](https://github.com/l0rraine/baozi/releases) 下 `baozi-vX.Y.Z-windows-amd64.zip`，解压到任意目录
（**别放 `Program Files`**：它要往自己旁边和 `%LOCALAPPDATA%` 写东西，那里没权限），双击 `baozi.exe`。

**三个 exe 必须留在同一个目录**：`baozi.exe` 会在自己旁边找 `baozi-hook.exe`（双击 Ctrl 的钩子）
和 `baozi-index.exe`（可选，设置里一键装成后台索引服务）。

## 三个窗口

| 窗口 | 怎么打开 | 干什么 |
|---|---|---|
| 搜索面板 | 双击 Ctrl / 托盘「显示 Baozi」 | 搜文件、应用；跑命令；搜索框右侧 `.*` 切正则 |
| Baozi 设置 | 面板底栏「设置」/ 托盘「设置…」 | 所有配置都在这里，改完点「保存并应用」生效 |
| Baozi 文件互传 | 面板底栏「互传」/ 托盘「文件互传…」 | 局域网链接、跨网直传、顺手发一段文本 |

## 快捷键

| 键 | 作用 |
|---|---|
| 双击 Ctrl | 显示 / 隐藏面板。面板还在、焦点被别的窗口拿走时，这一下是**取回焦点** |
| `↑` `↓` | 选择结果（首页按行移动） |
| `←` `→` | 左右移动一格（焦点在输入框里也生效） |
| `Enter` | 打开选中项（应用走 Shell，文件走默认程序，命令带参数） |
| `Ctrl+Enter` | 打开选中项**所在文件夹** |
| `Ctrl+Shift+C` | 把选中项**所在目录**复制到剪贴板 |
| `Ctrl+K` | 固定到首页「已固定」区 / 取消固定 |
| `Esc` | 清空输入、回到首页 |

鼠标：结果行和首页卡片单击即打开；右键可「固定 / 取消固定」「从历史删除」。

## 搜索怎么用

- **中文敲拼音**：`dbgz` → 豆包工作，`jsq` → 计算器，也能敲全拼 `doubaogongzuo`。
- **多词用空格分开**，每个词都要命中：`snowshot video` 会把 `SnowShot_Video_*.mp4` 顶到第一条。
- **要按模式找就点输入框右边的 `.*`**：进入正则模式，只按正则精确匹配（不查拼音、不拆词），
  对象是文件名、不含目录。写错了会直接说「正则无效：……」。

  | 想找什么 | 正则 |
  |---|---|
  | 所有日志 | `.*\.log$` |
  | 2026 年的图片 | `^2026.*\.(jpg\|png)$` |
  | 名字带 rpt 或 backup | `rpt\|backup` |
  | 忽略大小写 | `(?i)readme` |

- 应用优先于普通文件，但结果里会固定留名额给文件和目录，不会搜单个字母就满屏应用。
- 图片、视频、PDF 在结果行显示内容缩略图；不想要可以在设置里关掉。
- 排序是「频次 > 类型 > 准确性」，三项权重、类型优先级、最多结果数都能在设置里调。

### 明明有这个文件却搜不到

1. 它在不在索引范围里？默认搜 `C:\`、`D:\`，`node_modules`、`.git`、`WinSxS`、AppData 下的缓存目录
   永远跳过（这些规则只能往上加、删不掉）。
2. `Recent` 目录也被排除：那里全是 `.lnk`，会把你真正想找的文件挤出去。
3. 「包含隐藏文件」只管隐藏**文件**，隐藏**目录**照样会进去。
4. 装了索引服务时，非 NTFS 卷（exFAT U 盘、网络盘）会被跳过，那些盘上的文件搜不到是预期的。
5. Baozi 自己的数据目录（`%LOCALAPPDATA%\Baozi`：`config.json`、`baozi.log`、索引文件）**搜得到**，
   但它是「收录但不跟实时变化」的：那里文件的时间戳要等下一次全量重建才刷新，属正常现象。
   （这个目录要是真被排除掉，它每 5 秒写一次索引增量、每次唤出写一行日志，就会把自己的写入
   当成"用户动了文件"再索引一遍——自己喂自己。）

改完根目录 / 排除目录不用手删索引文件，`BAOZI_REINDEX=1` 启动一次就会按新规则重建。

## 自定义命令

自带三条电源命令，不用自己写脚本：

| 敲什么 | 效果 |
|---|---|
| `关机 30` | 30 分钟后关机（必须带分钟，不带只弹用法提示，不会裸关机） |
| `睡眠` | 立即待机 |
| `睡眠 30` | 30 分钟后待机 |
| `取消关机` | 取消已经排上的关机或睡眠 |

脚本本身随程序走（`%LOCALAPPDATA%\Baozi\scripts\shutdown-after.ps1`，启动时自动落盘并补 BOM），
配置里只记 `builtin:shutdown`，换机器、换用户目录都不会指空。

加自己的命令（Listary 那种映射）：设置 →「自定义命令」→ 右边编辑选中的那条。

| 字段 | 说明 |
|---|---|
| 激活词 | 面板里敲的词，例如 `term` |
| 别名 | 同一命令的其它叫法，命中任意一个都算 |
| 显示名 | 结果列表里显示的文字 |
| 程序 | 可执行文件、脚本，或 `builtin:shutdown` 这类内置引用 |
| 参数 | 见下面占位符；留空就直接追加你敲的词 |
| 工作目录 | 留空继承 Baozi 自己的；支持 `{dir}` |
| 执行后收起面板 | 开终端这类窗口时关掉它 |

**程序栏填脚本就行**：`.ps1` 自动包成 `powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File <脚本>`，
`.bat` / `.cmd` 包成 `cmd.exe /c`，不用自己拼那一长串。设置页底部的「将执行：」会显示最终命令行。

参数里的占位符：

| 占位符 | 含义 |
|---|---|
| `%1` … `%9` | 激活词后面第 1～9 个词（按空格切） |
| `%*` | 后面所有词，空格连成一条 |
| `{dir}` | 跟随到的文件管理器目录（没开跟随就是空串） |

规则一条：**写了占位符就只按模板替换，不再追加用户词；一个都没写才把后面敲的词追加到末尾**。
所以 `关机 30` → 脚本收到 `30`；而 `term` 这种没写占位符的命令，`term D:\work` 照样加参数。

## 文件对话框跟随

不用唤出面板：打开「另存为」框停在「文档」，去资源管理器切到「下载」，再切回那个框，
**它的路径自己变成「下载」**。

来源支持资源管理器、Total Commander、Directory Opus、XYplorer、xplorer2、tessoa、Arke，每种都能在设置里单独关掉。
Arke 走它自己的 `--api` state 接口，双栏里取活动窗格的那个目录。
只认标准 `#32770` 对话框；Electron / Qt 自绘的那种不覆盖。整个功能也可以一键关掉。

## 局域网文件互传

分享是**一次性临时链接**，到点自动失效：

1. 打开「Baozi 文件互传」；
2. 「添加文件 / 添加文件夹」（还没生成链接也可以先加）；
3. 选「链接有效期」，默认 1 小时（10 分钟 / 30 分钟 / 2 / 8 / 24 小时可选）；
4. 点「生成链接」，得到：
   - **4 位访问码**（单独大字显示，手敲比抄地址快，区分大小写）；
   - `http://192.168.x.x:端口/s/xxxx/` 地址 + 二维码 + 剩余时间；
   - 「绑定网卡」：机器上有 VMware / MuMu / Hyper-V 虚拟网卡时，在这里固定成真正联网的那块
     （换网卡后链接和访问码都会换新）；
5. 到期或点「停止共享」，端口立刻关闭，链接马上打不开。

几个特点：

- 只分享一项时打开链接**直接开始下载**；多项时给一个列表页；
- 文件**支持断点续传**；文件夹实时打包成 zip 流下载（不落临时文件、没有体积上限，但 zip 流不能续）；
- **只发不收**：页面里没有上传入口，对方不能往你这台电脑写东西；
- 连续输错访问码 20 次会自动停止共享，防局域网脚本穷举；
- 第一次共享时 Windows 防火墙会弹一次放行提示。

**只想递一段话也行**：窗口里有「顺带发一段文本」输入框，对方打开页面就能看到，旁边有「复制」按钮。

## 跨网直传

局域网那条只在同网段管用，跨网走 WebRTC，两端直连、不经过云盘。

- **对方也装了 Baozi**：切到「跨网直传」页签 → 发送方加文件、点「生成短码」（6 位，排掉了 `0 o 1 l i`）
  → 接收方填码、选保存位置、点「开始接收」。连上后进度条走，连接方式标「直连」或「经中继」。
- **对方什么都不装**：生成短码后会多给一条 `https://signal.1jia.life/r?code=短码` 的网页地址，
  对方浏览器打开就是接收端（数据先攒内存、收完存到下载目录，适合中小文件）。

文本一样能发，而且排在文件前面，对方一收到就先看到那段话。

打不通的情况：对称 NAT、公司/校园网会拒掉打洞，目前只报「两端网络都没打通（对称 NAT 或防火墙）」，
TURN 中继留了口子但还没接。

## 快速索引服务

默认是普通目录扫描（能用但慢）。设置 →「索引」→「启用快速索引（需管理员）」会弹一次 UAC，
把 `baozi-index.exe` 装成自动启动的服务：不遍历目录，直接读 NTFS 的 USN Journal，整机 174 万条 17 秒建完，
之后新文件**实时**可见（服务每 5 秒把增量写进 `index.delta`，面板每次唤出先追平）。

- 服务是可选、可停的；没装或停了，主程序按心跳文件自动回退到自己扫，不会卡住；
- 只支持 NTFS 卷，exFAT U 盘/网络盘会被跳过；
- USN 里没有文件大小和修改时间，所以服务建的索引这两项是 0（结果不显示、排序也不依赖）；
- 停用并卸载同样一次 UAC：先停服务再删注册项，**不删索引和配置**。

排障看 `%LOCALAPPDATA%\Baozi\baozi-index.log`。

## 托盘、开机自启、卸载

托盘菜单：显示 Baozi、设置…、文件互传…、重新建立索引、打开配置文件、开机启动、卸载、退出 Baozi。
点「退出 Baozi」会先停掉对话框跟随、通知钩子进程退出、历史落盘，再退进程。

开机自启写在 `HKCU\...\CurrentVersion\Run`（值名 `Baozi`），不是计划任务、不用管理员，
任务管理器「启动」页可以单独禁用。自动启动那次**只待在托盘、不弹面板**。

卸载「卸载：清除自启与数据…」会先弹系统确认框，确认后摘自启、停服务、退钩子，
再删掉整个 `%LOCALAPPDATA%\Baozi`（配置、历史、索引、日志）。`baozi.exe` / `baozi-hook.exe` 本体保留，
下次双击就是全新状态。托盘点不出来时可以命令行兜底：

```powershell
$env:BAOZI_UNINSTALL=1; .\dist\baozi.exe
```

## 设置里能改什么

- **常规**：双击 Ctrl 开关与间隔（默认 200 毫秒）、备用组合键（默认 `Alt+Shift+Space`，留空不注册）、全屏时抑制、
  开机自启；**界面外观**：圆角 / 透明度 / 投影三个开关 + 图标大小；文件对话框跟随总开关 + 六种来源逐项开关；
  排序三条权重、类型优先级、最多结果数、缩略图开关；索引根目录、排除目录、包含隐藏文件、立即重建。
- **自定义命令**：左边一列命令、右边编辑选中的那条。
- **面板大小/位置**：没有设置项，直接**拖四条边**改大小、**按住空白处拖**移动，
  松手 0.8 秒后写进配置，下次启动照旧。
- **图标大小**的台阶是倍数（50%～200%），100% 就是系统缩放下的默认大小；选「自定义」时用一条滑杆
  调**像素**（125% 屏上范围 14～83，默认 27.5）。首页卡片的大图标会一起放大，一排自然少放几张。
- 点「保存并应用」后会写盘、重注册组合键、重启钩子进程、必要时重建索引，不用退出软件。

数据都在 `%LOCALAPPDATA%\Baozi`：`config.json`、`history.json`、`index.bin`、`baozi.log`。
配置删了也不会崩，缺什么补默认值。

## 更新

「关于」页会在启动后后台查一次 GitHub Releases，也可以在页面上点「立即检查」。
代理那行是一个复选框「使用代理 地址」：**打开设置窗口时现场读一次**环境变量和系统代理，
勾掉就一律直连。地址只用来显示，不落盘。

发现新版本可以点「下载并更新」：它自己下载 zip、解压、写一个 PowerShell 脚本，退出后由脚本覆盖三个 exe
并重新拉起。全过程写 `%LOCALAPPDATA%\Baozi\update.log`，「上次更新」那行就是读它。

不用界面也能推一次更新（快捷方式/计划任务可用）：

```powershell
.\baozi.exe --update-now
```

`baozi.debug.exe` 不参与自更新（会拒绝，提示用 zip 替换）；本地构建（`tools\build.ps1` 注入的
`vX.Y.Z-N-g<hash>`）也照常比较版本，只有完全没注入版本号的 `dev` 才不提示。

## 出问题先看这几处

日志在 `%LOCALAPPDATA%\Baozi\baozi.log`（超过 2MB 自动清空重来）。GUI 子系统没有控制台，报错都写这里。

- **唤出后打字打不进去**：日志里正常是 `toggle: 显示面板`；出现「抢前台失败」只会在前台是 UAC 提权窗口
  这类极少数情况，把那几行发出来就能定位。
- **搜不到文件**：见上面「明明有这个文件却搜不到」四条。
- **互传手机打不开**：先确认防火墙放行了；机器有虚拟网卡时在互传窗口「绑定网卡」里固定真网卡。

调试用的环境变量（少数几个常用的）：

| 变量 | 作用 |
|---|---|
| `BAOZI_DATA_DIR` | 换一套独立的数据目录，做互不干扰的配置 |
| `BAOZI_HEADLESS=1` | 起来但不弹面板 |
| `BAOZI_OPEN=settings` / `share` | 启动后直接打开对应窗口 |
| `BAOZI_DEBUG=1` | 日志里打印每次查询和打开 |
| `BAOZI_REINDEX=1` | 强制重建一次索引 |

## 从源码构建

需要 Go 1.27.3 或更新、Windows 10/11。

```powershell
pwsh -File tools\build.ps1              # 三个 exe 一起编，参数与 Release 一致
pwsh -File tools\build.ps1 -Version v0.4.2
```

`build.ps1` 做三件手工 `go build` 容易漏的事：

- **带 `-H=windowsgui`**：不带的话 PE 子系统是 Console，双击先弹黑窗，看起来就像调试版；
- **注入 `version.Version`**：不带的话关于页显示"开发版"（源码里默认 `dev`）；
  默认取 `git describe --tags --long`，例如 `v0.4.1-8-g24630f2`，不会冒充正式版；
- 编完自检 PE 子系统必须是 GUI(2)，不是就直接报错。

手工编也可以，但这两条都要带上：

```powershell
$ver = (git describe --tags --long)
go build -trimpath -ldflags "-H=windowsgui -s -w -X baozi/internal/version.Version=$ver" -o dist\baozi.exe ./cmd\baozi
go build -trimpath -ldflags "-s -w" -o dist\baozi-hook.exe  ./cmd\baozi-hook
go build -trimpath -ldflags "-s -w" -o dist\baozi-index.exe ./cmd\baozi-index
```

**别用 `Start-Process` 起它**：那样它是终端/编辑器的子进程，宿主一退 Windows 会把整棵进程树收走。
`tools\restart.ps1` 走 `Win32_Process.Create` 让 WMI 服务去起，父进程是 `WmiPrvSE.exe`，和终端没父子关系：

```powershell
pwsh -File tools\restart.ps1              # 重启 dist\baozi.exe
pwsh -File tools\restart.ps1 -ShowLog     # 起来后打日志尾巴
```

改代码前想先看结构，读 [`docs/architecture.md`](docs/architecture.md)：窗口、玻璃底图、索引、互传、
更新各自为什么这么设计都写在那。
